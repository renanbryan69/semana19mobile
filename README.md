# semana19mobile



1. Quais são os principais serviços de armazenamento em nuvem?
Os principais são Google Cloud Storage, Amazon S3 e Microsoft Azure Blob Storage. A escolha depende do preço, segurança, espaço disponível e das necessidades do projeto.

2. Por que definir a localização do bucket?
Porque a localização pode influenciar a velocidade de acesso aos dados, os custos e também questões de segurança e legislação. Para uma empresa no Brasil, por exemplo, pode ser interessante escolher uma região próxima.

3. O que são classes de armazenamento?
São opções que definem como os dados serão armazenados e quanto custará o serviço. Para arquivos que são acessados poucas vezes, uma classe como Coldline pode ajudar a reduzir os custos.

4. Como criar uma política de retenção?
É possível definir um período para manter os arquivos armazenados. No exemplo, a política poderia ser configurada para manter os dados por um ano e, depois desse período, permitir a exclusão automática conforme as regras do serviço.

Assim, o bucket fica mais organizado, seguro e com custos controlados.
